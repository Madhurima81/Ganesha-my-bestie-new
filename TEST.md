## How to use this file

### Generate test cases for a scene
"Read CLAUDE.md, TESTCASES.md, and NAVIGATION.md.
Read [scene file path from sceneRegistry.js].
Generate all test cases for this scene.
Add them under the correct section below.
Flag all gaps before testing begins."

### Report results after manual testing
"Scene 05 testing done.
Pass: 1,2,3,5. Fail: 4 — VO doubles on return. Gap: 6 — not built.
Update TESTCASES.md."

### Fix a failing case
"Read TESTCASES.md. Scene 05, Case 04 is failing — VO doubles on return.
Read the JSX and fix it. Mark as [F→FIXED] when done."

---

## Status keys
[ ] not tested yet
[P] PASS — tested manually, works
[F] FAIL — tested, broken — add note on same line
[S] SKIP — not applicable to this scene
[G] GAP — feature not built yet, cannot test
[F→FIXED] was failing, now fixed — retest needed

---

## Rules for Claude Code
- Never mark any case as [P] — only Madhurima marks PASS
- Always flag gaps before Madhurima starts testing
- All fixes go in the JSX — never change test cases to hide a bug
- After fixing a gap, change [G] to [ ] so Madhurima can test it
- After fixing a fail, change [F] to [F→FIXED] so Madhurima can retest
