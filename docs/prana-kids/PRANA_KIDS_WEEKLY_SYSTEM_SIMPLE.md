# Prana Kids Weekly System (Simple)

This is the lean version to use for 52+ weeks.

## Root Structure

```text
PRANA KIDS/
├── 01_Master_Assets/
├── 02_Master_Templates/
├── 03_Weeks/
├── 04_Master_Story_Catalog/
└── 05_Final_Exports/
```

## What Each Folder Does

- `01_Master_Assets`
  Locked reusable library: characters, environments, props, symbols, UI.
- `02_Master_Templates`
  Locked Canva or layout templates for carousel, story, reel, printable.
- `03_Weeks`
  Active production folders, one folder per week.
- `04_Master_Story_Catalog`
  One place that tracks every story, title, character, value, and illustration reference.
- `05_Final_Exports`
  Final approved exports only.

## Week Folder Structure

```text
03_Weeks/
└── Week 01/
    ├── WEEK_OVERVIEW.md
    ├── Story 01/
    │   ├── story.md
    │   ├── illustration_brief.md
    │   └── exports/
    ├── Story 02/
    ├── Story 03/
    ├── Story 04/
    └── Story 05/
```

## What Goes Inside Each Story Folder

### `story.md`

- final story text
- reflection question
- affirmation
- tiny challenge
- parent note
- teacher note

### `illustration_brief.md`

- story ID
- title
- page-by-page scene notes
- character IDs
- environment IDs
- prop IDs
- symbol IDs
- layout IDs

### `exports/`

- approved carousel
- approved story version
- approved reel version
- approved PDF if needed

## Why This Is Better For 52+ Weeks

- fewer folders to maintain
- easier for a small team to understand
- every story stays self-contained
- final outputs do not get mixed with drafts
- one central story catalog makes long-term planning easier

## Recommended Naming

### Weeks

- `Week 01`
- `Week 02`
- `Week 03`

### Stories

- `Story 01`
- `Story 02`
- `Story 03`

### Story IDs

- `ST-W01-01`
- `ST-W01-02`
- `ST-W01-03`

## Keep This Rule

Only keep what is needed for production:

- story text
- illustration brief
- final exports

Do not create extra draft folders unless there is a real need.
