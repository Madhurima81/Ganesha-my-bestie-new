- [2026-09-24] GMB Hint Standard v1's L3 threshold counts an 8s gap from when the L2 hint line finishes speaking (via a `markLevel2VoiceEnded`-style callback / onEnd), NOT a fixed 26s-from-idle-arm timer. A fixed timer lets a slow L2 line overlap or get cut off by L3. This is now the standard across every scene with an idle-hint ladder (Modak, Pond, Eyes/Ears/Sacred Assembly, About Me Hut's Favorite Food + Dreams and Wishes, and all 8 Shloka River scenes via the shared `useRepeatedHintCycle` hook's `markLevel2VoiceEnded`). Don't reintroduce a flat L3 timer when adding new hint ladders — always gate L3 on L2's actual voice completion, with a fixed-timer fallback only for the muted/no-VO case.
- [2026-09-24] `GestureDemo` (shared component) needs a `replayKey` prop passed at every call site where the same `active` condition covers multiple escalating hint levels (e.g. `effectiveHintLevel >= 2` covers both L2 and L3) — without it, the demo plays once on the first `active` `false→true` transition and never replays on the next level. Pass the hint-level value itself as `replayKey`. Don't revisit unless GestureDemo's internal re-arm logic changes.
- [2026-09-24] Wrong-action feedback rule (Symbol Mountain, locked design): for each *distinct error type* within a mechanic (e.g. Bush's wrong-direction vs. too-short swipe are separate types, tracked with separate counters) — 1st occurrence gets physical feedback (spring-back/ring-drain/snap-back) + a short corrective VO specific to that error; 2nd occurrence is physical feedback only, no VO; 3rd occurrence repeats the VO and re-shows the teaching gesture demo. Each occurrence resets the idle-hint clock. Drag mechanics (Marsh/Reeds/Garland carry) and tap mechanics (Eyes/Ears) are exempt from the 1st-occurrence VO — a snap-back or wobble is already sufficient there, escalate only via the normal idle-hint ladder on repeats.
