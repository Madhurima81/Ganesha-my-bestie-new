🎨 Design Philosophy
🧱
Layer A: Zone Base Colors (The Walls) Muted, calming tones that set the emotional mood. These are zone-specific and create the environment.
🎮
Layer B: Global Play Palette (The Toys) Bright, consistent colors for ALL interactive elements across ALL zones. Green buttons, gold stars - always the same!
👶
Child-Friendly UX Principle Zone colors are soft and muted so they don't overwhelm. Interactive elements are bright and consistent so kids know what to tap.
✨
Color Balance Rules • Base colors: 70% of screen (backgrounds, containers)
• Accent colors: 10% maximum (borders, headers)
• Play colors: 20% (buttons, stars, interactive elements)
🎯
Key Changes from Current Implementation • Symbol Mountain: Changed from warm sand/gold to cool misty tones (better for focus)
• Festival Square: Kept warm saffron/marigold (removed green scheme)
• Shloka River: Balanced between green and aqua (softer sage-water blend)
• Cave: Lighter earth tones instead of dark cave (better visibility)
• About Me: Warmer terracotta instead of bright orange (more cozy)
