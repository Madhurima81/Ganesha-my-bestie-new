# V2 Template Architecture Map
## Date: 2026-08-12

Status: **LOCKED architecture working specification**

Purpose:
Replace the legacy 23-template realization model with a smaller mechanism-first V2 production set. The legacy 23 remain as historical/reference material and are not deleted. V2 templates are defined by causal mechanism first, then tested against the real situation library before selector mappings or implementation are changed.

## V2 Design Principles

1. One template = one distinct causal engine.
2. Situation first, template second.
3. No invented coverage or manufactured bestForSituations mappings.
4. Every V2 template owns its realization/event-chain logic; no generic fallback is allowed inside V2.
5. Modes are permitted only when real situation evidence shows genuinely different mechanisms.
6. The ending must prove the mechanism through protagonist action, not merely state the true belief.
7. Shared prose is acceptable only when it is genuinely connective; repeated mechanism-bearing sentences are a quality defect.
8. V2 must be evaluated against the full active situation library before production selector work begins.

## Production Set Status

Therefore:

## V2-01 - Cumulative Discovery

Legacy lineage:
T01 / LOGIC_CUMULATIVE_BUILD.

Core engine:
Multiple concrete facts or trail fragments accumulate and point to one underlying pattern. The realization comes from the whole pattern, not one isolated clue.

False-belief shape:
The protagonist interprets each event separately or assumes the immediate obstacle is the whole problem.

True-belief shape:
The individual fragments mean something together, revealing a deeper cause or need.

Required beats:
SETUP -> TRAIL_1 -> TRAIL_2 -> TRAIL_3 -> PATTERN_BREAK -> DISCOVERY -> RESOLUTION.

Causal test:
Could the resolution exist without all three accumulated fragments? If yes, the mechanism is probably not cumulative discovery.

Best-fit situation signature:
Situations with three or more authored concrete details that accumulate toward one causal insight.

Anti-patterns:
Generic bridges; abstract pattern language replacing real details; jumping to the lesson before the accumulated trail is complete.

## V2-02 - Ritual Escalation

Legacy lineage:
T02 / LOGIC_RITUAL_ESCALATION; T08/T18 waiting-pattern variants inform failure distinctions.

Core engine:
The same old response, avoidance, or performance-reactivity pattern returns under increasing pressure. The protagonist eventually pauses and breaks the pattern.

False-belief shape:
The old response feels automatic, necessary, safest, or like proof that force/repetition is the only way through.

True-belief shape:
The protagonist can interrupt the pattern and choose a different response.

Required beats:
PROBLEM -> REFRAIN_1 -> ATTEMPT -> REFRAIN_2 -> SETBACK -> PAUSE -> REFRAIN_CHANGED -> NEW_ACTION.

Causal test:
The pressure pattern must genuinely recur, whether outwardly or internally. The third pressure point must show interruption of the old pattern rather than a third repetition of the same mistake.

Best-fit situation signature:
Recurring triggers, repeated impatience, repeated avoidance, repeated control, recognizable behavioral loops, or repeated internal/performance spirals where the same reaction keeps returning.

Residual-coverage clarification:
This mechanism legitimately includes recurring internal patterns such as perfectionist retry-collapse, shame/defensiveness loops, concealment/monitoring loops, or repeated self-pressuring responses. The defining feature is still repetition plus interruption, not merely “trying again.”

Anti-patterns:
Three unrelated mistakes; generic “be patient”; changed wording with no changed behavior; generic try/fail prose; single-incident situations with no real returning pattern.

## V2-03 - Circular Return

Legacy lineage:
T05 / LOGIC_CIRCULAR_RETURN.

Core engine:
A recognizable situation returns after a middle journey and perspective shift. The external scene echoes the opening, but the protagonist responds differently.

False-belief shape:
The original scene is interpreted through a limiting identity, fear, comparison, or assumption.

True-belief shape:
The protagonist can meet a similar moment with a changed stance and outward response.

Required beats:
MIRROR_OPENING -> OLD_REACTION -> MIDDLE_JOURNEY -> INSIGHT -> MIRROR_ENDING -> NEW_REACTION.

Causal test:
Opening and ending must be directly comparable, and the new reaction must visibly differ.

Best-fit situation signature:
Situations with a recurring social/object/context moment that can plausibly return.

Anti-patterns:
Generic moral ending; unrelated middle journey; ending scene so different that the mirror disappears.

## V2-04 - Inversion

Legacy lineage:
T09/T15 inversion family.

Core engine:
A reasonable assumption or expectation is overturned by an unexpected contribution, helper, or evidence.

False-belief shape:
The protagonist assumes a person, option, or method cannot help or will produce the expected result.

True-belief shape:
The protagonist reinterprets what was dismissed and recognizes the missing contribution.

Required beats:
PROBLEM -> ASSUMPTION -> DISMISSAL -> SECOND_LOOK -> UNEXPECTED_CONTRIBUTION -> RESOLUTION.

Causal test:
The previously dismissed element must supply something necessary to resolution.

Best-fit situation signature:
Situations where the obvious assumption is plausible but a neglected person/option can contribute meaningfully.

Anti-patterns:
Obviously absurd wrong options; generic “someone helped”; reversal that changes nothing.

## V2-05 - Question Chain

Legacy lineage:
T04 / LOGIC_RUNAWAY_CHAIN.

Core engine:
Each clue answers part of the previous question but creates a narrower, more inward question, until the final answer is already implicit.

False-belief shape:
A surface answer seems sufficient or an immediate shortcut seems to solve the problem.

True-belief shape:
The deeper question reveals the real value, motive, or responsibility.

Required beats:
OPENING_QUESTION -> CLUE_1 -> QUESTION_2 -> CLUE_2 -> QUESTION_3 -> CLUE_3 -> REVELATION -> RESOLUTION.

Causal test:
Question 2 must arise from clue 1; question 3 must arise from clue 2; revelation must resolve the whole chain.

Best-fit situation signature:
Situations with ambiguity, temptation, responsibility, or curiosity where successive reasoning can narrow toward a deeper truth.

Anti-patterns:
Three unrelated “why” questions; abstract mission phrases; generic detective prose.

## V2-06 - Role Reversal

Legacy lineage:
T14 / LOGIC_ROLE_REVERSAL.

Core engine:
The protagonist receives meaningful help, later recognizes a similar struggle in someone else, and becomes the giver of the same kind of help.

False-belief shape:
The protagonist feels alone, misunderstood, incapable, or believes receiving help is the endpoint.

True-belief shape:
What was received can be consciously passed on.

Required beats:
HERO_RECEIVES -> LEARNING -> OTHER_STRUGGLES -> RECALL_HELP -> HERO_GIVES -> RESOLUTION.

Causal test:
The later helping action must meaningfully rhyme with the earlier received help.

Best-fit situation signature:
Situations where a child can plausibly receive a concrete form of help and later encounter a parallel relational need.

Anti-patterns:
Generic kindness; unrelated rescue; internal empathy without action; no receive/give symmetry.

## V2-07 - Countdown / Resource Pressure

Legacy lineage:
T11 / LOGIC_RESOURCE_DEPRECIATION.

Core engine:
A finite-feeling resource, chance, time window, or emotional margin shrinks. Rushing appears safer, but the protagonist pauses and makes a better final move.

False-belief shape:
Acting faster is safer; slowing down wastes the remaining chance.

True-belief shape:
A deliberate pause can improve the quality of the final action.

Required beats:
COUNTDOWN_3 -> COUNTDOWN_2 -> PRESSURE_PEAK -> PAUSE_CHOICE -> COUNTDOWN_1 -> RESOLUTION.

Causal test:
The pause must materially change the final action and explain success.

Best-fit situation signature:
Limited chances, shrinking time, narrowing options, or mounting pressure where one quality decision matters.

Anti-patterns:
Artificial three tries; countdown words without real scarcity; pause that changes nothing; lucky success.

## V2-09 - Judgment / Trickster Choice

Legacy lineage:
T12 / LOGIC_TRICKSTER.

Core engine:
A plausible first choice falls short; a more sophisticated second choice still misses something; reflection exposes what both missed; a third choice acts from the true belief.

False-belief shape:
The protagonist thinks the first practical or sophisticated answer is enough.

True-belief shape:
The protagonist recognizes the missing moral/emotional dimension and chooses accordingly.

Required beats:
SETUP -> CHOICE_A_PLAUSIBLE -> CHOICE_B_BETTER_BUT_FLAWED -> REFLECTION -> CHOICE_C_TRUE -> RESOLUTION.

Causal test:
Choice C must repair a specific limitation shared by A and B.

Best-fit situation signature:
Real decisions with multiple plausible options and a non-obvious missing consideration.

Anti-patterns:
Obvious strawman A/B; generic try harder; C merely stating the moral; no consequence.

## V2-10 - Threshold Choice

Legacy lineage:
T19 / LOGIC_THRESHOLD_CROSSING.

Core engine:
Two genuinely live moral or behavioral paths compete at a decisive threshold. The protagonist deliberately chooses, and the consequence follows from that exact choice.

False-belief shape:
The tempting path promises belonging, relief, success, safety, or convenience at a meaningful cost.

True-belief shape:
The protagonist acts from the deeper value even when the tempting path remains attractive.

Required beats:
APPROACH_CROSSROADS -> OPTION_OLD_BELIEF -> OPTION_NEW_BELIEF -> CHOICE -> CONSEQUENCE -> RESOLUTION.

Causal test:
Both paths must remain genuinely available until the choice, and the consequence must be specific to the chosen path.

Best-fit situation signature:
Cheating, theft, peer pressure, honesty, responsibility, integrity, retaliation/de-escalation, compassionate stepping-in, or other moments where a child must actively choose.

Anti-patterns:
Obvious right/wrong options; choice without temptation; generic praise after the choice; consequence unrelated to decision.

## V2-11 - Attention Shift

Legacy lineage:
T13 / LOGIC_THRESHOLD_CROSSING attention-shift branch.

Core engine:
The protagonist becomes fixated on one thing as the source of safety, worth, relief, or completion. An interruption redirects attention to a deeper or more meaningful thing, and that widened attention changes what matters.

False-belief shape:
The trapped focus is assumed to be the thing that will restore safety, worth, or relief.

True-belief shape:
Attention can widen; something deeper matters more than the trapped focus.

Required beats:
LOSS_OR_FIXATION -> SEARCH_OR_HOLD -> INTERRUPTING_NOTICE -> DEEPER_DISCOVERY -> RETURN_OR_REFRAME -> REASSESSMENT -> RESOLUTION.

Causal test:
The widened attention must genuinely change the perceived value of the original fixation. A literal return/find beat is allowed but not required if a reframe serves the same causal function.

Best-fit situation signature:
Fixation on loss, comparison, deprivation, replayed fear, absence, obsessive checking, or moments where one trapped focus narrows the whole emotional field until attention widens.

Residual-coverage clarification:
This mechanism legitimately includes fixations on what someone else has, on missing attention, on denied treats/outings, on replayed frightening imagery, or on other absences where the trapped focus dominates meaning until a deeper value reorders it.

Anti-patterns:
Generic “look on the bright side”; unrelated discovery; ending that leaves the original fixation fully primary; stories where the protagonist was never actually trapped on one thing.

## V2-12 - Quiet Strength

Legacy lineage:
T09 / quiet-strength inversion branch.

Core engine:
The protagonist believes force, visible effort, intensity, or continued pushing is required. That obvious approach fails or proves insufficient. A quieter capacity already present in the protagonist is noticed and used.

False-belief shape:
The problem requires force, volume, speed, constant effort, or another visible display.

True-belief shape:
A quieter capacity such as patience, steadiness, rest, calm, noticing, grounding, care, or gentle self-regulation is sufficient and effective.

Required beats:
BIG_EXPECTATION -> BIG_ATTEMPT_FAILS_OR_THINS -> QUIET_QUALITY_NOTICED -> QUIET_ACTION -> RESOLUTION.

Causal test:
The quiet capacity must directly explain why the final action succeeds where force or continued pushing was insufficient.

Best-fit situation signature:
Situations where calm, care, steadiness, rest, grounding, pacing, sensory settling, or another quiet capacity can plausibly solve what force cannot.

Residual-coverage clarification:
This mechanism legitimately includes internal-capacity situations such as fatigue, unfamiliar environments, fear, overstimulation, bedtime unsettlement, and other moments where the child does not need a bigger action so much as a quieter, more regulating one.

Anti-patterns:
Generic “try less”; abstract calm; quiet action unrelated to the actual problem; success without causal proof.

## V2 Coverage Audit - Required Before Implementation

Before any V2 template is coded into the selector:

1. Run all 156 active situations through the current resolver/selector.
2. For each situation, identify which V2 mechanisms genuinely fit.
3. Record strongest fit and runner-up where useful.
4. Flag situations with no V2 fit.
5. Identify mechanisms with zero natural coverage.
6. Do not create mappings merely to improve coverage percentages.
7. If two V2 templates compete for the same situation, resolve the collision by causal fit, not template ID or alphabetical order.
8. A V2 template is only production-worthy when its natural stories demonstrate the mechanism and its realization does not collapse into generic prose.

## V2 Acceptance Gate

A V2 template can be promoted only after:

- natural coverage exists;
- its contract is implemented on the live path;
- representative natural stories pass complete-story and Story QA;
- mechanism is visible in prose;
- situation-specific facts drive the causal beats;
- same-mode stories do not collapse into noun-swapped copies;
- C13 is reviewed with precise scope;
- blind read passes;
- full production readiness remains intact.

## Legacy 23 Policy

The legacy 23 are retained as reference/history.

No further rescue work should be undertaken merely to preserve their original count.

Legacy templates that have already produced useful realization patterns become lineage/reference for V2. The goal is not to preserve one-to-one compatibility with all 23. The goal is a smaller, clearer, mechanism-first production system.
