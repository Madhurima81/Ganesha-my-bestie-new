# Shloka River — Game Flow (Scenes 10–14)
For VO scripting reference. Describes what the child sees and does at every step.

---

## Scene 10 — Vakratunda + Mahakaya

### Opening Modal
- Modal appears with Ganesha image
- Child taps **Let's Go**

---

### Vakratunda Game

- River scene. A frog sits on the left bank. Frog family waiting on the right.
- 3 material piles appear on screen — lily pads, stones, logs
- Child taps one pile to select it
- 4 empty slots appear across the river (stepping stones)
- Child drags pieces one by one from the pile onto the slots
- Each piece placed → one syllable lights up in the bar at top: **VA → KRA → TUN → DA**
- All 4 placed → frog hops across slot by slot with hop SFX
- Frog reaches family → family bounces → reunion

---

### Mahakaya Game

- New scene. A baby elephant calf is pinned under a heavy log blocking the river
- A rope hangs from above with a grip handle
- Child drags the rope knob down to the log → knob snaps onto log (chime)
- A pull handle appears on the rope
- Child drags the pull handle downward
- As they pull → log rises → syllables light up: **Ma → ha → ka → ya**
- Pull to 100% → log flies up → calf is freed → "We lifted it together!" appears on screen

---

### After each game completes
- Sparkle animation briefly
- Flip card (SymbolAutoReveal) appears with symbol image + affirmation text
- Child taps the card → it flies to the sidebar icon
- Next game begins

### End of Scene
- Fireworks
- InnerMandala with 2 petals glowing
- SceneCompletionCelebration screen

### SuryakotiGame

- A dark riverbank scene. A bunny is somewhere, lost
- Child rubs the screen to clear the darkness (like rubbing a foggy window)

- Syllables light up as they rub

- Child shares / distributes light between both sides

## Scene 12 — Nirvighnam + Kurumedeva

### Opening Modal
- Modal appears with Ganesha image
- Child taps **Let's Go**

---

### NirvighnamGame

- River path scene. A sad turtle sits on one side. Her nest is on the other side.
- 3 obstacles block the path between them: a stone, a branch, a reed
- Child drags each obstacle off the path one by one
- Each obstacle cleared → syllable lights up: **NIR → VIGH → NAM**
- All 3 cleared → turtle swims along the path waypoints → reaches her nest → happy turtle
- On-screen text: *"The path is clear!"*

---

### KurumedevaGame

- River scene. A sad beaver needs to cross but there's no bridge.
- 4 friends are waiting with materials: Turtle (log), Bird (vine), Squirrel (pegs), Bunny (planks)
- Only one friend glows at a time — child taps that friend
- Each tap → friend sends their material flying to the bridge spot → bridge builds one step
- Syllables light up: **KU → RU → ME → DE → VA**
- All 4 tapped → bridge complete → beaver walks across
- On-screen text: *"The bridge is ready! Everyone helped!"*

---

### After each game
- SymbolAutoReveal → child taps → flies to sidebar

### End of Scene
- Fireworks → InnerMandala (2 petals) → SceneCompletionCelebration

## Scene 13 — Sarvakaryeshu + Sarvada

### Opening Modal
- Modal appears with Ganesha image
- Child taps **Let's Explore**

---

### SarvakaryeshuGame

- 4 situation cards shown one at a time
- Each card shows: a picture of a problem + situation text + 4 power icons to choose from

| Card | What child sees | Right answer |
|------|----------------|-------------|
| 1 | Puzzle piece won't fit | Vakratunda |
| 2 | Child wants to give up | Mahakaya |
| 3 | Two kids want the same bike | Samaprabha |
| 4 | Grandma needs help with bags | Kurumedeva |

- Child taps a power icon
- Wrong: gentle message *"That power could help too..."* — correct one glows as hint
- Correct: icon flies across to the image → image transforms (before → after) → feedback text appears → syllable lights up
- Syllables: **SAR → VA → KAR → YE → SHU**
- All 4 done → *"Ganesha helps in all things!"* appears on screen

---

### SarvadaGame

- Background changes to show time of day — 3 phases: Morning → Afternoon → Night
- Each phase: a floating memory bubble drifts on screen with a *"Tap!"* hint on it
- Child taps the bubble → bubble expands → a memory card appears showing a before scene → flips to after scene → bubble bursts
- Each burst → syllable reveals: **SAR → VA → DA**
- After all 3: *"SARVADA — Always"* text floats onto screen

---

### After each game
- SymbolAutoReveal → child taps → flies to sidebar

### End of Scene
- Fireworks → InnerMandala (2 petals) → SceneCompletionCelebration

## Scene 14 — Shloka River Finale

### Opening Modal
- Modal appears with Ganesha image
- Child taps **Let's Explore**

---

### ARRANGE

- River scene with 8 empty numbered slots in a grid
- Below: 8 word-boat chips in shuffled order — each has the symbol icon + word label on a boat shape
- Active slot (slot 1 first) glows to show where to place next
- Child drags a boat chip OR taps it → placed in the active slot
- Correct: chime + ripple animation + checkmark → next slot activates
- Wrong: red flash + wrong SFX → chip returns to tray
- Child must fill slots in order 1 → 2 → 3 → 4 → 5 → 6 → 7 → 8
- Progress counter shows *"2 / 8"*, *"3 / 8"* etc.
- Hint system if idle:
  - 10s → slot glows brighter
  - 20s → correct boat glows in tray
  - 35s → correct boat wiggles

All 8 placed → *"You completed the Shloka River! ✨"* overlay appears

---

### RECAP

- Animated boat sails across the screen
- Each of the 8 words flashes one by one with its symbol icon (1 second each)
- Dot progress indicator at bottom shows which word is current
- Word audio plays for each word as it appears

---

### FINALE

- Full shloka card appears on screen:

```
Vakratunda    Mahakaya
Suryakoti     Samaprabha
        🪷
Nirvighnam    Kurumedeva
Sarvakaryeshu Sarvada
```

- *"MASTER!"* badge appears
- Fireworks auto-trigger

---

### End of Scene
- InnerMandala with all 8 petals glowing
- Message: *"The complete shloka lives inside you now"*
- Child taps close → SceneCompletionCelebration (8 stars, final scene)
